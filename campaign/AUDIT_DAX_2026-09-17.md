## Bugs found & fixed
1. **Stale champion verification gate (F1).** `bt/verify_champion_r3_cmd.sh` reproduced the OLD
   R3/pre-ITER19 map: it still fed `brwt15` (pruned by ITER19) and a non-existent A5r2 path
   (`HUNT_BASIS1/...`). Fix: rewritten to mirror `rawew13v2_build.PATHS` exactly (12 sleeves;
   A5r2 from `campaign/agents/A5_vol_cond`).
2. **verify_champion hardcoded ITER15 shrinkage (F1).** `_relw_from` used module constant
   `SHRINK_D=0.62`; the ITER19 pruned champion re-selected **0.98** under the same pre-committed
   minsharpe rule. No CLI override existed, so the gauntlet could never pass for the ITER19 book.
   Fix: threaded a `shrink` param through `_relw_from`→`verify_champion` and added `--shrink`
   (default unchanged = 0.62); the r3 cmd now passes `--shrink 0.98`. Champion gauntlet now ok=True.
3. **Test-order pollution (F2).** `team/agents/RES_STATARB/test_hunt_r1.py` and
   `team/tests/test_res_basis_r1.py` both did `import hunt_r1 as H`, colliding on
   `sys.modules["hunt_r1"]` — whichever was collected first won. Fix: each now loads its own
   `hunt_r1.py` from its own directory via importlib under a unique alias (deterministic).
4. **RES_STATARB `ls_weights` tie bug (F3, real).** Tied trailing signals (rank default
   `method="average"`) made top-k and bottom-k sets overlap → >k legs per side and
   non-dollar-neutral rows. Fix: `rank(method="first")` + explicit disjoint long/short masks +
   degenerate-tie flat guard (exactly k disjoint legs per side, dollar-neutral on all live rows).
5. **RES_STATARB test contract off-by-one (F5).** `test_weights_dollar_neutral` demanded 21 rows
   flat but `rolling(21)` is valid from index 20 (warmup is 20 rows); and asserted side sums
   ±1 over the warmup (contradicting the flat check). Fix: warmup 20, live span iloc[21:],
   side-sum checks scoped to live rows. All 4 tests pass.
